# Form + settings

`FormLayout` / `ValidationSummary` account form plus `SettingsCard` preferences persisted with QtCore **`Settings`** (`Prefs` category, `schemaVersion`). Window frame uses `geometryPersistenceKey: "FormSettingsExample"`.

Recipes: [`docs/forms.md`](../../docs/forms.md) · [`docs/settings-persistence.md`](../../docs/settings-persistence.md) (**1.65**).

```bat
cmake --build build --config Release --target qwinui3_example_form
build\qwinui3_example_form.exe
```
