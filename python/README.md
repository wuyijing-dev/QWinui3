# QWinUI3 Python modules

**Docs:** [packaging-python.md](../docs/packaging-python.md)

## Run Gallery

```bat
pip install PySide6
python scripts/qwinui3.py python
```

From repo root (or use **`python-gallery.cmd`** on Windows).

## Packages

| Directory | Role |
|-----------|------|
| `qwinui3/` | Bootstrap for PySide6/PyQt6 + shared kit (`create_engine()`, runtime diagnostics) |
| `qwinui3_gallery/` | Full Gallery entry |
