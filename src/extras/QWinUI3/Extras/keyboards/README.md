# Keyman layout packs + in-app IME tables

Compiled `.kmx` from [keymanapp/keyboards](https://github.com/keymanapp/keyboards)
(`basic_kbdus`, `basic_kbdgr`, `basic_kbdfr`, `basic_kbdes`, `basic_kbdru`, `basic_kbda1`).

Pinyin tables: [NOTICE-pinyin.md](../../../../../docs/NOTICE-pinyin.md).
Layouts go through SIL Keyman Core. zh-Hans uses `PinyinLexicon`; ja-JP is `RomajiKana`; ko-KR is `HangulComposer`. UI chrome stays in `OnScreenKeyboard.qml`.
