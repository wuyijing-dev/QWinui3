# Compatibility 4.xx (draft)

**Status:** Draft — fills at **4.00** ([checkpoint-400](checkpoint-400.md))

After **4.00**, the **4.xx** line promises:

- No breaking QML/C++ API removals without a new major
- Default control appearance and page/nav **transition durations** stay stable
- Efficiency budgets from [checkpoint-390](checkpoint-390.md) remain the documented baseline

Breaking changes belong in **5.00+**, not patch minors.

See also: [compatibility-3xx.md](compatibility-3xx.md) · [upgrade-notes.md](upgrade-notes.md)
